## 🎯 Project Objective

AtliQ Media wanted a **clean, simple, fact-based election story** for the **2026 Tamil Nadu Assembly Election**.

Most election coverage focuses only on statewide seat totals. This project goes deeper by answering three audience-friendly questions:

> **How much changed?**  
> **Where did it change?**  
> **How competitive were the contests?**

The goal was not to explain why voters behaved differently. The goal was to use election-result data to build a clear, neutral, and visual story for a media leadership team.

---

## 🧠 Headline Finding

> **Tamil Nadu did not move as one uniform story.**  
> The 2026 election is clearer when viewed through **constituency realignment, regional shift, and close contests.**

## ✅ Data Validation Framework

To ensure accuracy and reproducibility:

- Used **AC Number** as the primary key.
- Identified winners using **maximum vote count**.
- Verified all **234 constituencies**.
- Reconciled flipped and retained seats.
- Validated regional totals.
- Checked party seat counts.
- Calculated margins using winner and runner-up vote totals.
- Avoided causal claims, predictions, and voter-behavior assumptions.

---

## 🧮 Core Calculation Logic

### Winner Identification

```sql
SELECT
    ac_number,
    constituency,
    party,
    votes
FROM election_results
WHERE votes = (
    SELECT MAX(votes)
    FROM election_results e2
    WHERE e2.ac_number = election_results.ac_number
);
```

### Flip Logic

```sql
CASE
    WHEN winner_2021 <> winner_2026 THEN 1
    ELSE 0
END AS flipped
```

### Victory Margin

```text
Victory Margin = Winner Votes - Runner-up Votes
```

## ⚠️ Limitations

This project is strictly **descriptive**.

### It answers:

✅ What changed  
✅ Where it changed  
✅ How much changed  
✅ How close the contests were  

### It does **not** explain:

❌ Why voters behaved differently  
❌ Whether demographics caused the results  
❌ Whether campaign strategy caused the results  
❌ What may happen in future elections
